# RentaTica

Proyecto SaaS para administrar alquileres de equipo. La lógica de negocio se
implementa en SQL Server y el API actúa como capa de transporte.

## Carpetas

- `backend/`: código del API REST.
  Guia de instalacion, configuracion y endpoints: `backend/README.md`.
- `database/`: esquema, datos iniciales, funciones, procedimientos, triggers y
  pruebas SQL. El orden de instalación está en [database/README.md](database/README.md).
- `docs/`: propuesta, requisitos del curso, diccionario de datos y diagramas.
  El índice está en [docs/README.md](docs/README.md).

## Inicio

Para desplegar y probar la base de datos, seguir el orden indicado en
`database/README.md`. Revisar las instrucciones del curso y el diccionario antes
de cambiar el modelo o las reglas de negocio.
